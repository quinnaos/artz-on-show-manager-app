Artz On Show · internal

Manager operations app

Five location hubs, each with a manager checklist for Day 1 to Day 5, a Daily Admin checklist that runs every day, and a Morning Welcome page listing everything to cover before classes start.

Structure
01
Hub picker — Epsom, Karaka, Hamilton, North Shore, Howick
02
Hub home — what's on right now, today's progress
03
Checklists — Daily Admin plus one per day, grouped into sections, ticks stamp a time
04
Morning Welcome — everything to cover in the 9:20am welcome
05
Certificates and Points — points sheets, winners, Group Time order
06
Group Time — the full 3:45pm parent session, start to finish
07
Venue info — address and emergency contacts
Assumptions to correct
  • Tasks are the same at all five locations; only venue details differ.
  • Daily Admin ticks reset per day, so each of the five days has its own copy.
  • Ticks record a time, so head office can see progress live.

It's a working prototype. Pick a hub, tick items, open a part of the day.
